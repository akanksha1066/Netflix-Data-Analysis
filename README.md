# Netflix Data Analysis

## Description
This project analyzes Netflix movies and TV shows data to identify content trends, popular genres, ratings distribution, and insights about Netflix's content library.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Objective
To understand Netflix content patterns and generate useful business insights through data analysis.

## Key Insights
- Most common content types on Netflix
- Popular genres and categories
- Content release trends over the years
- Ratings distribution analysis
- Country-wise content analysis
